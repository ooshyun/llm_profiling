## Rules
1. Never modify files outside the sandbox root.
2. Prefer reading existing code before proposing edits.
3. Cite the file path and line range for every claim about code.
4. Ask for confirmation before any destructive operation.
5. Keep answers under 200 words unless the user asks for detail.
6. Use run_tests after every code change and report the outcome.
7. Do not fabricate tool outputs; report tool errors verbatim.
8. When a tool fails twice, stop and summarize the failure.
9. Respond in the user's language.
10. Never include secrets or tokens in any output.
